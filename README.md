# Mini Game App

Bromo Quiz Game — mini game kuis interaktif tentang Gunung Bromo.

## Fitur (rencana)

- Mode kuis dengan bank soal (kategori: geografi, geologi, budaya; difficulty: easy/medium/hard)
- Penjelasan jawaban (explanation) tiap soal
- Panel admin dengan fitur Import CSV untuk upload soal massal
- Format CSV: `question, option_a–d, correct, category, difficulty, explanation, isActive`
